02 / 记忆的分量

不是把每句话存起来，
而是让重要的事，
有机会再次被想起。

记忆会被检索、串联，也会随时间淡去。你能打开记忆本与织库，看见这些内容，而不只是相信一句“我记住了”。

  • 往事串成记忆链，联想与时间检索一起寻找线索。
  • 被更正的旧内容收起，新的事实不必与旧说法挤在一起。
  • 世界设定区分“我的设定”与“TA 记下的·待你确认”。

04 / 浪漫之外，认真打磨

你可以决定，
这份陪伴是什么样子。

从性格到声音，从外观到能力。拥爱提供可以配置的空间，也把权限与使用边界留给你。

01

聊得自在，听得见

文字、图片理解与实时语音；按住说话或自动聆听，语音播放可以打断。识图和语音需相应服务配置。

02

每个角色，自己的模样

性格、头像、关系与模型可分别设置。七款皮肤、明暗模式和中英界面，让外观也符合你的偏好。

03

可以主动，也懂得留白

角色可主动搭话、回访约定、分享生活。作息与频控帮助减少打扰；备忘和日程让交代的事有记录可查。

04

按需连接，逐项授权

插件与 MCP 扩展工具，外部聊天渠道连接角色。Android 手机感知是可选能力，开启前需授权。

05

一起生活，各自管理

多账号与家庭关联分开管理，角色隐私内容可以上锁。服务器控制台集中管理账号、默认模型与功能权限。

06

用量看得见，选择有依据

按用途、模型与渠道查看调用和 token 用量，区分估算与实测。模型、语音、生图服务由你配置。

05 / 由你掌管的家

陪伴可以亲近。
数据的边界，也要清楚。

自托管让你掌管存储与服务。哪些能力开启、接入哪家模型、数据怎样备份，都由部署者配置。

A home of your own.

存储在自己的实例

聊天、记忆、日记与角色数据存放在你部署的电脑或服务器上。备份与访问权限也需要由部署者妥善管理。

A key in your hands.

凭据加密，权限可控

模型凭据加密存储，主密钥单独保存。升级或迁移时请妥善备份主密钥；丢失后需重新填写相关凭据。

Open to inspection.

开源，可以查看与修改

源码公开，可自行部署、修改和审查。手机感知、插件与设备行动按权限使用，不需要为了聊天开启全部能力。

自托管 ≠ 自动离线。使用云端模型、语音、识图或其他外部服务时，相应内容会发送给你配置的服务商。若选择本地服务，能否完全本地运行取决于具体配置。

06 / 从这里开始

先安放服务，
再把伙伴带到手机上。

需要一台能持续运行的电脑或服务器、一个 Android 手机，以及可用的模型服务。首次部署包含依赖与模型下载，请预留时间。

  1. 部署后端

    可选 Windows 一键脚本、Linux / macOS 脚本或 Docker。具体环境要求和安装步骤以仓库 README 为准。

  2. 安装 Android 应用，连接服务

    从发行版下载 APK，填写手机可访问的服务器地址。本官网是产品介绍页，不是在线聊天入口。

  3. 配置模型，创建角色

    在 API 配置里填入你自己的模型端点与密钥，再设置角色。语音、识图和生图按需另外配置。

  4. 按自己的节奏开启能力

    先从聊天开始，再尝试记忆、生活与插件。开放公网前，请做好 HTTPS、账号管理和数据备份。

开始之前，
你可能想知道。

下载应用就能直接用吗？

需要先部署后端，或连接你获准使用的实例。应用本身不附送公共服务器和模型服务。

拥爱免费吗？模型调用怎么计费？

你可以获取开源源码并自行部署。电脑或服务器、模型 API、语音与生图服务可能产生费用，具体以你选择的服务商为准；开源不等于这些服务免费。

iPhone 或浏览器可以使用吗？

目前提供 Android 应用。面向 iOS 用户的 PWA 路线仍在规划中，尚未提供可用版本。

记忆和主动消息会一直准确吗？

不会作这样的保证。角色的理解与表达受模型、上下文及设置影响，可能记错或遗漏。你可以查看、修正和删除记忆，也可以调整相关功能。

遇到安装或使用问题，去哪里反馈？

先查看 仓库说明，再通过 问题反馈描述版本与复现步骤。请勿在公开反馈中附上密钥或未经处理的私人聊天记录。
