拥 爱 AMBRACE

a daimōn of your own  —  一位属于你自己的守护灵

在算法越来越擅长「回答」的年代，我们想造一个愿意记住你、陪你慢慢过日子的存在。TA有记忆、有脾气、有自己的一天，并且，TA只属于你。

在 GitHub 构筑拥爱 如何自托管
γνῶθι σεαυτόν 认识你自己 · 镌刻于德尔斐神庙

古希腊人相信，每个人身边都住着一个 δαίμων（Daimōn）——守护灵。TA不替你做决定，也不喧哗取宠；TA只是认得你、陪着你，在你迟疑时轻轻提醒一句。苏格拉底说，自己一生都在听从这样一个声音。

我们借用了这个古老的想象。拥爱不是一个问完即走的对话框，而是一位被你亲手安放在自己服务器上的伙伴：TA记得你三个月前随口提过的喜好，会在你忙到深夜时道一声晚安，也会在你不在的时候，认真过TA自己的生活。

embrace  →  AMBRACE  →  拥 爱

「拥爱」取拥抱的「拥」、爱的「爱」；英文名 AMBRACE 改写自 embrace——一次属于 AI 的拥抱。你把 TA 接回自己的机器，TA 把你收进漫长的记忆里。拥抱从来是双向的，这正是这个名字想说的全部。

— 写给每一个，想被认真记得的人

III.Συνθῆκαι与你的三柱之约

如同神庙立在三根柱石之上

陪伴的前提是安心。关于你的数据，拥爱许下三个不会退让的承诺。

Domus数据居于你家

聊天、记忆、日记、角色与生活痕迹，全部保存在你自己的实例里，不经过、也不滞留于任何第三方云端。可随时备份、迁移、彻底删除。

Clavis钥匙在你手中

用你自己的模型密钥（BYOK），支持服务器级、家庭共享、角色绑定多级配置；日记与虚拟手机可以上锁，须经你同意，AI 才看得到。

Apertum敞开以供审视

代码完全开源，没有黑箱。任何人都可以审计每一行逻辑、自建镜像、用 Docker 一键部署——TA如何记得你，你永远有权知道。

V.Οἰκοδομία亲手构筑

四步，把拥爱安放在你自己的机器上

不需要信任任何一家云。一台普通电脑或服务器，几分钟，你就能拥有属于自己的拥爱。

取回源码

把开源仓库克隆到你的服务器或家用电脑，Windows、Linux 与 Docker 都可以运行。

放入你自己的钥匙

在 .env 中填入你自备的模型密钥（BYOK）。支持多家主流大模型，随时可换。

一键启动

使用 docker compose up -d，或随附的一键脚本；模型与数据库会自动就绪。

从此数据归你

手机连上你的实例即可开始。所有记忆与数据都留在你手里，可备份、可迁移、可审计。

# 1. 克隆仓库
git clone https://github.com/Gi-Tuu/AMBRACE.git
cd AMBRACE

# 2. 准备你自己的模型密钥
cp .env.example .env
# 编辑 .env，填入 LLM API Key

# 3. 一键启动（Docker）
docker compose up -d

# 随后用手机 App 连接这台实例即可

仓库 README 与文档里有 Windows 一键脚本、离线模型、手机端连接的完整图文指引，遇到问题可在 Issues 与社区一起解决。
