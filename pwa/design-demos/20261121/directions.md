# PWA 三方向 · 2026-11-21

> 输入：PWA 核心功能已对齐；本轮只做视觉方向，不改生产代码。
> 受众：在自己电脑/手机上记录生活、被 AI 角色记住的人。
> 共同 spec：1440×900 桌面、390×844 手机；四个面＝对话 / 记忆 / 生活 / 角色；内容用测试账号「测试·小阳、小冰、小云」；头像用姓名印记，不伪造真人照片。
> 共同约束：正文 ≥14px、正文对比 ≥4.5、可点区域 ≥44px；不用紫色渐变、emoji 图标、灰色占位块。

## 六个候选

### 1. 呼吸 / 原研哉（最佳设计师 · 克制）
- 借的机制：留白不是空，是让内容自己站住；一条页面只放一个重心，辅助信息退到页边。
- 不借：原研哉的白色极简、无印式产品摄影。
- 自己长：纸色偏米、墨色偏暖；呼吸线从对话的停顿里长出来。
- 主角素材：文字本身 + 一条“呼吸线”；头像为姓名印记。
- 骨架：86px 竖轨 + 宽正文 + 右侧页边批注；对话是稀疏的横向条目。
- 胆量：把大片空白当作主视觉；当前记忆只在页边露出一角。
- form 来自内容：AI 陪伴里真正稀缺的是“允许不回答的空隙”。

### 2. 重拍 / 服部一成（最佳设计师 · 大胆）
- 借的机制：字的粗细、大小、裁切就是层级；让一个汉字承担整屏的情绪。
- 不借：服部一成的具体海报构成、红黑配色。
- 自己长：近黑 + 纸白 + 信号红；标题用宋体，正文用无衬线；最新一句用红色竖线“重拍”。
- 主角素材：巨大汉字 + 衬线对话。
- 骨架：不对称海报网格；对话是横向大字条目，记忆是 2×2 的重量块。
- 胆量：角色名首字做成背景巨字；最新一句被红色下划线压住。
- form 来自内容：关系里真正有重量的是“这一句”，不是消息数量。

### 3. 夜航工作台 / Linear（现实参照 · 密度）
- 借的机制：三栏工作台 + 顶部搜索 + 右侧上下文；用层级和发丝线而不是卡片阴影；键盘/命令面板先于鼠标。
- 不借：Linear 的紫色、具体品牌图标。
- 自己长：深海蓝黑 + 荧光青绿；等宽字体承担“运行时/记忆索引”的冷静感。
- 主角素材：真实数据密度（记忆 1,541、召回 132ms）。
- 骨架：232px 角色栏 + 中央消息流 + 320px 上下文栏；`/` 打开命令面板。
- 胆量：把“记忆命中”做成终端式 tool 标记，而不是一张普通卡。
- form 来自内容：记忆检索本来就是一次带索引的夜航。

### 4. 编读 / Readwise Reader（现实参照 · 阅读）
- 借的机制：待读队列是纯文字条目；正文窄栏、衬线、进度线；高亮是荧光笔而不是卡片。
- 不借：Reader 的品牌字体、黄色高亮具体色。
- 自己长：暖纸 + 墨黑 + 赭红；记忆按“读过的段落”排列。
- 主角素材：真实对话摘录。
- 骨架：目录 + 长文阅读栏；记忆是摘录卡。
- 胆量：对话像一封信，而不是聊天流。
- form 来自内容：角色记住的是“被划线的句子”。

### 5. 内容瀑布 / 小红书（秒数轮盘 · App #7）
- 借的机制：双列错落卡片流，封面高度不一；标题两行；作者/点赞在下。
- 不借：小红书红、真实社区内容。
- 自己长：生活流作为“共同生活封面墙”。
- 主角素材：生活片段的文字封面（没有真实图片，不假造照片）。
- 骨架：双列 masonry，顶部频道。
- 胆量：把记忆按“可浏览的封面”而不是时间表排列。
- form 来自内容：共同生活是被一张张片段记住的。

### 6. 节气色谱 / 中国传统色（秒数轮盘 · 东亚 #7）
- 借的机制：节气/季节决定色彩，颜色是时间的索引；低饱和、成组出现。
- 不借：具体节气海报的插画。
- 自己长：记忆按季节分成色带，每个季节有一个主色。
- 主角素材：色带 + 日期。
- 骨架：时间轴按季节分段，色带贯穿。
- 胆量：整屏只有色彩与日期，文字退后。
- form 来自内容：记忆有季节，关系也有。

## 选中的三版

**1 呼吸**、**2 重拍**、**3 夜航工作台**。

理由：
- 三者骨架不同：稀疏页边 / 海报字重 / 三栏工作台；不是同一套卡片换皮。
- 覆盖三种温度：安静、张扬、冷静高效。
- 都能承载“对话、记忆、生活、角色”四个面，且不依赖不存在的图片。
- 第 4–6 版保留为备选，不进入正式版。
