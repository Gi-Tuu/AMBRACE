# PWA 软件方向 · 2026-11-22

> 纠正上一版：上一轮把“设计方向”做成了海报。PWA 本质是软件，先满足信息架构、操作效率、状态完整性和可读性；视觉只负责层级与气质。
> 共同 spec：1440×900 / 390×844；四个模块＝对话、记忆、生活、设置；内容用测试账号；不做全屏巨字、不做海报拼贴、不做隐喻压过功能。

## 六个候选（三套逻辑各两个）

### 1. Calm Workbench / 原研哉式克制（最佳设计师）
- 机制：四栏主从结构；页边留白，但每个操作都有位置。
- 不借：无印良品的白色神化、产品摄影。
- 自己长：暖白 + 墨 + 苔绿；细边框；对话像工作记录。
- 主角素材：真实会话与记忆条目。
- 骨架：64px 竖轨 + 268px 列表 + 主区 + 288px 上下文。
- 胆量：最大胆的是“敢留白”，不是“敢放大”。

### 2. Functional Grid / Rams 式功能主义（最佳设计师）
- 机制：克制的网格、明确的分组、所有控件可解释；不靠装饰。
- 不借：Braun 的产品外观与橙色。
- 自己长：灰白 + 深灰；等宽只用于数据。
- 骨架：工具栏 + 双栏数据区。
- 胆量：把“无装饰”做到极致。

### 3. Reader / Readwise Reader 式阅读（现实参照）
- 机制：左收件箱 + 右长文；正文窄栏、衬线、阅读进度；操作贴内容。
- 不借：Reader 的品牌字体与高亮黄。
- 自己长：暖纸 + 墨 + 赭红；对话当一篇可读的往来。
- 主角素材：真实对话/记忆摘录。
- 骨架：300px 收件箱 + 阅读区；移动端列表→阅读。

### 4. Control Room / Linear 式密度（现实参照）
- 机制：左侧模块、中央工作区、右侧上下文；工具栏 + 命令搜索；细线分栏。
- 不借：Linear 的紫色与品牌图标。
- 自己长：夜蓝 + 青绿；等宽承担数据；状态色只给运行态。
- 骨架：200px 导航 + 主区 + 300px 上下文；移动端底部导航。
- 胆量：信息密度，而不是视觉噱头。

### 5. Feed / 小红书式内容流（秒数轮盘 App #7）
- 机制：双列错落卡片，封面高度不一。
- 不借：品牌红与真实社区内容。
- 自己长：生活片段用文字封面，不伪造照片。
- 骨架：双列 masonry。
- 胆量：记忆按“可浏览的封面”排列。

### 6. Season / 节气色谱（秒数轮盘 东亚 #7）
- 机制：颜色是时间的索引，按季节分段。
- 不借：节气插画。
- 自己长：低饱和色带 + 日期。
- 骨架：时间轴。
- 胆量：色彩成为导航。

## 选中的三条软件线

**1 Calm Workbench**、**3 Reader**、**4 Control Room**。

- 三者主从结构不同：四栏工作台 / 双栏阅读 / 三栏控制台。
- 三个都能承载真实操作与状态，不是海报。
- 5/6 保留为备选，不进入生产。

## 文件

- `workbench.html` — 四栏工作台
- `reader.html` — 收件箱 + 阅读器
- `dashboard.html` — 控制台
- `shots/` — 桌面/手机截图
