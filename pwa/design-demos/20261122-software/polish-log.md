# polish-log · PWA 软件三方向

## 总原则

- 上一版（2026-11-21）把方向做成了海报，尤其是“重拍”：巨字、拼贴、装饰压过功能。用户指出“本质上是软件”，该版废弃，不作为候选。
- 本轮重新按软件标准做：导航、列表、详情、上下文、操作、空/错/加载状态；三版差异放在主从结构与信息密度。

## 01 工作台

- 看：四栏在 1440 下每栏都有用；左栏会话列表、中央对话、右侧上下文，不堆卡片。
- 看：记忆页列表 + 详情同屏，编辑/置顶/归档/删除都有位置。
- 改：移动端隐藏列表和上下文，只留主区 + 底部模块导航；底部导航不遮输入框。
- 留：暖白 + 苔绿，维持轻量，不抢内容。

## 02 阅读器

- 看：首屏是“收件箱 + 文档”，不是聊天气泡流；正文 15px/1.95，窄栏。
- 改：移动端首版只有阅读区、无法切模块——补底部导航（对话/记忆/生活/设置）。
- 改：桌面端保留收件箱，移动端收件箱收起，避免两栏挤在 390px。
- 留：衬线标题只用于内容标题，不用于 UI 标签。

## 03 控制台

- 看：三栏高密度；记忆页是索引表 + 召回分布 + 待复核，不是巨大卡片。
- 改：首版 composer 悬空，已改为消息区 flex 撑满、输入贴底。
- 改：移动端导航改底部四键，隐藏右侧上下文与顶部 crumb。
- 留：夜蓝 + 青绿，强调色只给运行态与召回命中。

## 验证

- Chrome 截图：1440×900、390×844；三版控制台 0 报错。
- 未跑 skill 自带 `design_lint`（本机 Playwright 缺 chromium_headless_shell），用 Chrome 手动截图与人工检查替代。
- 未改生产 PWA；等用户选方向。
